# Memory Capsule

Create a modern, beautiful and fully functional web application called TIME CAPSULE.

IMPORTANT: This is a digital time capsule platform, NOT a game. Do not create a pixel world, map, avatars or multiplayer game.

MAIN IDEA:

Users can create digital memory capsules containing photos, videos, personal stories and music. They can choose a future date when their capsule becomes available to open.

DESIGN:

Create a unique visual identity:

* Colorful transparent glass orbs representing memory capsules.

* Beautiful transparent tubes connecting and carrying the orbs.

* Smooth animations and elegant transitions.

* Soft gradients, glassmorphism and modern typography.

* A magical, nostalgic and emotional atmosphere.

* Responsive design for phones and computers.

MAIN PAGES:

1. HOME PAGE

* Website name: TIME CAPSULE.

* Tagline: “Your memories. Your people. Your moments.”

* Animated colorful orbs moving through transparent tubes.

* Each orb represents a user’s memory capsule.

* A button: “Create your capsule”.

* A section showing the user’s capsules.

2. CREATE CAPSULE

    Users should be able to:

* Enter a capsule title.

* Upload photos and videos.

* Write a personal story or description.

* Add a music link.

* Select the event date.

* Select a future opening date.

* Choose whether the capsule is personal or shared.

* Invite friends or family members.

3. CAPSULE PAGE

    Each capsule should display:

* Its title and cover image.

* The event date.

* The opening date.

* A countdown until opening.

* Invited participants.

* Comments and wishes.

* A locked state before the opening date.

4. SHARED CAPSULES

    The capsule owner can invite selected people.

    Invited participants can leave comments, wishes and, if permitted, upload their own photos and videos.

    Only authorized people can access a private capsule.

5. OPENING EXPERIENCE

    When the opening date arrives:

* The user receives an in-app notification.

* The capsule can be opened.

* Show a beautiful opening animation of the glass orb.

* Display photos and videos in a cinematic slideshow.

* Show the music link and messages from invited people.

6. PROFILE AND ARCHIVE

    Users can view their profile, created capsules and previously opened capsules.

TECHNICAL REQUIREMENTS:

* Use Supabase for authentication, database and file storage.

* Make registration and login functional.

* Save capsules and their information in the database.

* Make photo and video uploads functional.

* Protect private capsules.

* Check the opening date securely on the backend.

* Make the website mobile-friendly.

Start by building the complete visual structure and the main working features. Do not add unnecessary features. Prioritize a functional MVP over complicated animations or AI video generation
